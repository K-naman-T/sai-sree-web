# Round 8 ledger — spec: ROUND8.md

Directive: plan for a future CMS — a component that auto-arranges a client-added set of
images the way the current layouts look; images are iPhone landscape or portrait shots.

## Rulings

- R1: Composition is derived from the data, never mapped per page: count + portrait count +
  ratio classes (landscape / letterbox >= 1.55 / panorama >= 1.9). No title-based or
  index-based switch anywhere.
- R2: The planner is a pure module (`wallPlan.ts`) with no React imports, so it is testable
  standalone and reusable the day the CMS feeds runtime data.
- R3: Sibling groups of one shape rotate treatments for variety; aspect overrides
  (cinema, split, portrait-led mosaic/hang) are deterministic and do not consume rotation.
- R4: The viewport-fit rule holds for all normal counts (clamps per tile); 9+ plate groups
  may exceed one screen — a group that large has to.
- R5: Below lg every variant falls back to a single column of aspect-framed plates.
- R6: When the CMS arrives it owns order, captions, alt text and images; the planner owns
  composition only.
