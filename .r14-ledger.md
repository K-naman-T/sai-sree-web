## First-attempt note (kept, since it explains the padding)

Class order pitfall: `py-16` on the Section lost to the base `lg:py-20` when overridden with
a bare `pt-10` — breakpoint utilities win over base ones in the cascade. Overrides on this
Section must be written per breakpoint (`pt-10 sm:pt-10 lg:pt-10`). Same trap exists on any
Section whose padding is overridden without the breakpoint prefix.
